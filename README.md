# portfolio

Modern black-and-white, code-style portfolio website built with vanilla HTML, CSS, and JavaScript.

## Structure

```text
/assets
  /css
  /js
  /images
/pages
index.html
README.md
```

## Pages

- Home
- About
- Projects
- Experience
- Resume
- Contact

## Features

- Dark mode by default (black/white style)
- Mobile-first responsive layout
- Reusable shared header/footer components
- Smooth scrolling
- Scroll reveal animations
- Typing animation on home hero
- Project filtering on Projects page
- SEO + Open Graph metadata
- Favicon support
- GitHub Pages-ready static deployment (no backend)

## Customize

- Edit text/content directly in `index.html` and files in `/pages`.
- Update styles in `assets/css/styles.css`.
- Update interactions in `assets/js/app.js`.
- Replace `assets/images/resume-placeholder.pdf` with your real resume.
- Replace project links (`#`) with your GitHub and live demo URLs.
